1130Die Frage „Wo erschien das erste Input-Feld auf einer
1131Website?“ muss in drei verschiedene Fragen zerlegt

11341. Hatte die erste Website ein Eingabefeld?
1135
1136Die erhaltene Version der ersten Website am CERN be-
1137stand aus Text und Hyperlinks. Auf der erhaltenen
1138Startseite ist kein Formular- oder Texteingabefeld ent-
1139halten. Sie war zunächst ein navigierbares Infor-
1140mationssystem, kein Eingabesystem.
1141
11422. Was war der erste Mechanismus für Texteingabe im
1143Web?
1144
1145Bereits die HTML-Dokumentation von 1992 enthält das
1146Element <ISINDEX>. Es kennzeichnete eine Seite als
1147durchsuchbaren Index. Der Browser sollte daraufhin
1148eine Möglichkeit zur Eingabe von Suchbegriffen be-
1149reitstellen und diese als Query an den Server über-
1150mitteln. Eine W3C-Dokumentation von November 1992
1151beschreibt den Mechanismus ausdrücklich; ein Dokument
1152zum Line-Mode-Browser zeigt zudem, dass Keyword-Su-
1153chen bereits 1991 unterstützt wurden.
1154
1155Das ist sehr interessant für dich, weil <ISINDEX> kein
1156frei gestaltbares Feld innerhalb der Seite war. Das
1157Dokument teilte dem Browser lediglich mit: „Diese Res-
1158source ist durchsuchbar.“ Der User Agent stellte die
1159Texteingabe bereit.
1160
1161Damit könnte <ISINDEX> als eine Art Vorläufer von drei
1162späteren Elementen gelesen werden:
1163
1164Suchfeld Formular-Input Browser- beziehungsweise Such-
1165maschinen-Query 3. Wann erschien das heutige Prin-
