11251. Hatte die erste Website ein Eingabefeld?
1126
1127Die erhaltene Version der ersten Website am CERN bestand
1128aus Text und Hyperlinks. Auf der erhaltenen Startsei-
1129te ist kein Formular- oder Texteingabefeld enthalten.
1130Sie war zunächst ein navigierbares Informationssystem,
1131kein Eingabesystem.

11332. Was war der erste Mechanismus für Texteingabe im
1134Web?
1135
1136Bereits die HTML-Dokumentation von 1992 enthält das Ele-
1137ment <ISINDEX>. Es kennzeichnete eine Seite als durch-
1138suchbaren Index. Der Browser sollte daraufhin eine Mög-
1139lichkeit zur Eingabe von Suchbegriffen bereitstellen und
1140diese als Query an den Server übermitteln. Eine W3C-Do-
1141kumentation von November 1992 beschreibt den Mechanis-
1142mus ausdrücklich; ein Dokument zum Line-Mode-Browser
1143zeigt zudem, dass Keyword-Suchen bereits 1991 unter-
1144stützt wurden.
1145
1146Das ist sehr interessant für dich, weil <ISINDEX> kein
1147frei gestaltbares Feld innerhalb der Seite war. Das Do-
1148kument teilte dem Browser lediglich mit: „Diese Res-
1149source ist durchsuchbar.“ Der User Agent stellte die
1150Texteingabe bereit.
1151
1152Damit könnte <ISINDEX> als eine Art Vorläufer von drei
1153späteren Elementen gelesen werden:
1154
1155Suchfeld Formular-Input Browser- beziehungsweise Such-
1156maschinen-Query 3. Wann erschien das heutige Prinzip
