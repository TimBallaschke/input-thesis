7877## Zeitlichkeit: Verarbeitung vor der Bestätigung
7878
7879**Leitfrage:** Was wird bereits verarbeitet, während
7880ich noch formuliere und bevor ich meine Eingabe bestä-
7881tige?
7882
7883**Kernaussage:** Die Bestätigung einer Eingabe muss
7884nicht den Beginn ihrer technischen Verarbeitung markie-
7885ren. Bereits eine erwartete Fortsetzung kann vorberei-
7886tende Verarbeitung auslösen.

7889
7890- Formulieren, Verarbeiten und Bestätigen als unter-
7891schiedliche Vorgänge betrachten. - Die Vorstellung „erst
7892schreiben, dann absenden, dann verarbeiten“ hinterfra-
7893gen. - Technische Verarbeitung kann bereits während der
7894Eingabe stattfinden. - Am konkreten Beispiel unterschei-
7895den, welches Ereignis welchen Vorgang auslöst. - Daraus
7896nicht ableiten, dass jede Anwendung bei jedem Tasten-
7897druck Daten an einen Server sendet.
