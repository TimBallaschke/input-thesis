2241. **„Technische Interpretation“ ist bei dir noch eine
225Black Box.** Bei Touchscreens schreibst du etwa:
226
227> „…muss das System zudem die Position jeder Berührung
228interpretieren und der vermutlich beabsichtigten
229Taste zuordnen.“

231Das Wort **„vermutlich“** ist eigentlich hochinteres-
232sant. Das System empfängt nicht einfach eine ein-
233deutige Handlung, sondern produziert aus Messwerten
234eine plausible Intention. Dasselbe gilt noch viel
235stärker bei Sprache und KI. Die Eingabe existiert damit
236für das System nicht einfach – sie wird **klassi-
237fiziert, normalisiert und rekonstruiert**.

239Eine Steyerl-artige Zuspitzung wäre deshalb:
240
241**Zwischen körperlicher Handlung und digitaler Eingabe
242liegt kein neutraler Übertragungskanal, sondern ein
243technischer Interpretationsprozess, der entscheidet,
244welche Handlung als welche Eingabe lesbar wird.**

2492. **Sie würde wahrscheinlich das Wort „NutzerIn“ pro-
250blematisieren.** In deinem Text ist „der Nutzer“
251relativ souverän: Er hat eine Absicht, formuliert sie
252und versucht, das System dazu zu bringen, diese zu
253verstehen.

255Aber insbesondere bei KI-Systemen entsteht die Positi-
256on des Nutzers teilweise **erst im Verhältnis zum
257System**. Der Mensch lernt beispielsweise: - welche
258Fragen „funktionieren“, - wie detailliert ein Prompt
259sein sollte, - welches Vokabular das Modell versteht, -
260welche Dinge es verweigert, - welche Antwortforma-
261te zuverlässig erzeugt werden.

263Man passt also nicht nur die Eingabe an das System an.
264**Das System trainiert gewissermaßen auch den Nut-
265zer darin, wie er mit ihm sprechen soll.**

268sage theoretisch stärker machen. Momentan lautet
269die Aussage ungefähr: Nutzer müssen lernen, richtig zu

271
272**Die Interaktion produziert dabei sukzessive ein prak-
