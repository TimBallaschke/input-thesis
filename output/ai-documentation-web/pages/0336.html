319### 4. Welche Handlung wird hervorgehoben?
320
321[Text block] Die Anordnung eines Eingabefelds lässt
322sich nicht nur formal beschreiben, sondern auch
323daraufhin untersuchen, welche Handlung innerhalb einer
324Oberfläche besonders hervorgehoben wird. Ein gro-
325ßes, zentral platziertes Eingabefeld erhält dabei eine
326andere visuelle Gewichtung als ein kleines Feld,
327das zwischen weiteren Bedienelementen oder innerhalb
328eines längeren Formulars angeordnet ist.
329
330Diese Hervorhebung lässt sich als Teil einer entwor-
331fenen Nutzungsvorstellung betrachten. Akrich be-
332schreibt technische Objekte als Träger von Vorstellun-
333gen darüber, wie sie verwendet werden sollen und
334welche Rollen den beteiligten Akteur:innen dabei zukom-
335men (vgl. Akrich 1992, S. 207–209). Auf Interfaces
336übertragen bedeutet dies jedoch nicht, dass sich aus
337ihrer Gestaltung unmittelbar tatsächliches Nutzer-
338verhalten ableiten lässt. Beschrieben werden kann zu-
339nächst nur, welche Handlungen sichtbar bevorzugt
340angeboten oder in den Hintergrund gerückt werden.
341
342Die Analyse muss daher zwischen sichtbarer Hervorhe-
343bung und ihrer Interpretation unterscheiden. Dass
344ein Eingabefeld zentral platziert oder besonders groß
345gestaltet ist, ist beobachtbar; welche Nutzungs-
346vorstellung darin zum Ausdruck kommt, ist bereits eine
347analytische Deutung. Eine tatsächliche Wirkung auf
348das Verhalten der Nutzer:innen ließe sich daraus al-
