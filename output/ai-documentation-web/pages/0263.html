1374### 6. Zeitpunkt: Technische Verarbeitung beginnt nicht
1375erst mit dem Absenden
1376
1377- Bearbeitung, Übermittlung und Ausführung einer beab-
1378sichtigten Handlung unterscheiden. - Bereits Änderungen
1379eines Feldwerts können technische Ereignisse auslösen.
1380- Eine ausdrückliche Übermittlung ist deshalb ein be-
1381stimmter Verarbeitungsschritt, nicht der Beginn sämt-
1382licher Operationen. - Daraus nicht ableiten, dass jede
1383Anwendung bereits beim Tippen Daten an einen Server sen-
1384det. - Am jeweiligen Beispiel prüfen, welches Ereignis
1385welchen Vorgang auslöst.
