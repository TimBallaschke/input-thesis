846[Text block] Während Bearbeitung den aktuellen Text ver-
847ändert, beginnt Iteration erst mit einer Reaktion des
848Systems. Eine Fehlermeldung in einem Formular kann eine
849korrigierte Eingabe erforderlich machen, Suchergebnisse
850können neue Begriffe oder eine veränderte Query anregen
851(vgl. Seckler et al. 2014; Hearst 2009). Die Eingabe
852wird damit Teil einer Folge aus Formulierung, System-
853reaktion, Bewertung und erneuter Eingabe.
854
855Dieses Prinzip findet sich auch in dialogischen Sys-
856temen. Bereits ELIZA organisiert Interaktion als wie-
857derholte Abfolge von Eingabe und Antwort (vgl. Weizen-
858baum 1966). Bei LLM-Systemen kann eine Ausgabe wiederum
859zum Ausgangspunkt für einen veränderten Prompt werden.
860Diese Reformulierung erfolgt jedoch nicht zwangsläufig
861systematisch, sondern häufig lokal und anhand einzel-
862ner Ergebnisse (vgl. Zamfirescu-Pereira et al. 2023;
863Subramonyam et al. 2024). Das Texteingabefeld ist da-
864mit nicht nur eine Stelle zur einmaligen Eingabe, son-
865dern Teil einer zeitlichen Interaktionsfolge. [End text
