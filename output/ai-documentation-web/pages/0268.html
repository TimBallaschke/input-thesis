2210**Leitfrage:** Wie wird eine Eingabe verarbeitet, wel-
2211che Maßstäbe werden dabei wirksam und wie richten an-
2212dere Akteure ihre Inhalte daran aus?
2213
2214**Kernaussage:** Zwischen einer Eingabe und ihrem Er-
2215gebnis stehen technische Verfahren und gestaltete Be-
2216wertungskriterien. Inhaltsanbieter können ihre Angebote
2217wiederum an diesen Kriterien ausrichten. Das Ergebnis
2218entsteht deshalb nicht allein aus dem Anliegen der ein-
2219gebenden Person.

2221### Kurzer Auftakt: Wann beginnt Verarbeitung?
2222
2223- Technische Verarbeitung beginnt nicht grundsätzlich
2224erst nach dem Absenden. - Bereits die Veränderung eines
2225Feldwerts kann technische Ereignisse auslösen. - Verar-
2226beitung, Übermittlung und Ausführung einer beabsichtig-
2227ten Handlung unterscheiden. - Eine ausdrückliche Bestä-
2228tigung ist damit ein bestimmter Schritt, nicht notwendig
2229der Beginn sämtlicher Operationen. - Als Beispiel das
2230dokumentierte Such-Prefetching verwenden: Ergebnisse zu
2231einer vorgeschlagenen Fortsetzung können bereits vor
2232deren Bestätigung vorgeladen werden. - Vorbereitung und
2233bestätigte Auswahl bleiben unterschiedliche Vorgänge.
2234- Daraus nicht ableiten, dass jedes Eingabefeld bereits
2235beim Tippen Daten an einen Server übermittelt.

2342### 3. Anpassung an Auswahlverfahren
2343
2344Hier kommen Inhaltsanbieter als weitere Beteiligte hin-
2345zu.

2347- Drei Rollen unterscheiden: Nutzer\:innen formulie-
