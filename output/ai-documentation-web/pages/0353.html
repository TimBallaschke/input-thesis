3056
3057Ein Anliegen zu kennen bedeutet noch nicht, eine geeig-
3058nete Eingabe formulieren zu können. NutzerInnen müssen
3059einschätzen, welche Informationen ein System benötigt
3060und in welcher Form diese übermittelt werden sollten.
3061Eine Eingabe kann technisch akzeptiert werden, ohne zum
3062gewünschten Ergebnis zu führen. Entscheidend ist da-
3063her nicht nur, ob ein System eine Eingabe verarbeitet,
3064sondern auch, welches Wissen erforderlich ist, um sie
3065zielführend zu formulieren. Welche Anforderungen dabei
3066bestehen und wie leicht sie erschlossen werden können,
3067hängt auch von Entscheidungen derjenigen ab, die ein

3069207–209, 216).
