1447### 6. Zeitpunkt: Technische Verarbeitung beginnt nicht
1448erst mit dem Absenden
1449
1450- Bearbeitung, Übermittlung und Ausführung einer beab-
1451sichtigten Handlung unterscheiden. - Bereits Änderungen
1452eines Feldwerts können technische Ereignisse auslösen.
1453- Eine ausdrückliche Übermittlung ist deshalb ein be-
1454stimmter Verarbeitungsschritt, nicht der Beginn sämt-
1455licher Operationen. - Daraus nicht ableiten, dass jede
1456Anwendung bereits beim Tippen Daten an einen Server sen-
1457det. - Am jeweiligen Beispiel prüfen, welches Ereignis
1458welchen Vorgang auslöst.
