235[Text block] Mit der Verarbeitung einer Eingabe ist
236ihre Verwendung nicht notwendig abgeschlossen. Eine
237Angabe kann zunächst dazu dienen, das unmittelbare An-
238liegen der NutzerInnen zu erfüllen, und zugleich

243
244Dabei lassen sich verschiedene Vorgänge unterscheiden.
245Daten können übertragen, gespeichert, mit anderen
246Angaben oder einem Konto verknüpft und anschließend für
247weitere Aufgaben verwendet werden. Diese Schrit-
248te müssen jedoch nicht gemeinsam auftreten. Dass eine
249Eingabe beispielsweise an einen Server übertragen
250wird, bedeutet noch nicht, dass sie dauerhaft gespei-
251chert oder für einen anderen Zweck weiterverwendet
252wird.
253

255re Verwendung damit nicht automatisch fest. Welche

258staltung des Systems ab. Im Folgenden geht es deshalb
