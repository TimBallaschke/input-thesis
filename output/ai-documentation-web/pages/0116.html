357## Die Abgrenzung
358
359| Ebene | Hauptfrage | Form der Macht | | --- | ---
360| --- | | **Surface** | Was lässt mich das Feld glau-
361ben, tun zu können? | Macht der Rahmung | | **Interac-
362tion** | Wie muss ich mich verhalten, damit das System
363mich versteht? | Macht der Anpassung | | **Operation**
364| Was macht das System tatsächlich aus meiner Eingabe?
365| Macht der Entscheidung |
366
367„Wer will was von wem?“ kann dadurch in jedem Kapitel
368wiederkehren, aber jeweils anders:
369
370- Surface: Wer scheint hier zu wem zu sprechen? - In-
371teraction: Wer muss sich an wen anpassen? - Operation:
372Wer bestimmt, was aus der Eingabe folgt?

374## Ein Mechanismus darf mehrfach vorkommen
375
376Autocomplete muss beispielsweise nicht eindeutig einem
